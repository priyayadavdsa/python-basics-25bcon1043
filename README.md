# Python Basics

A collection of beginner-friendly Python programs demonstrating core programming concepts.

## Features
- Sum of two numbers
- Even or odd checker
- Largest of three numbers
- Factorial calculation
- Fibonacci sequence generator
- Student data management

## How to Run
python sum_two_numbers.py
python even_odd_check.py
python largest_of_three.py
python factorial.py
python fibonacci.py
python student_data.py
